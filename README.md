# NATUS VINCERE - Terlahir untuk Menang! 💪🔥

## Deskripsi

**NATUS VINCERE** adalah sebuah website motivasi yang mengajak kamu untuk terus berjuang dan menang dalam setiap hal yang kamu hadapi. Menggunakan animasi interaktif, tombol yang bergerak menghindar, dan pesan semangat yang muncul saat kamu memilih "Siap!", web ini dirancang untuk memberi energi dan motivasi kepada pengunjungnya. Dengan desain modern, animasi halus, dan tampilan yang responsif, NATUS VINCERE adalah tempat yang tepat untuk mengingatkan kita bahwa kita semua terlahir untuk menang! 💪🔥

Web ini dibuat dengan menggunakan HTML5, CSS3 (SCSS), dan JavaScript untuk menciptakan pengalaman yang menarik dan inspiratif.

## 🎯 Fitur

- **Animasi Interaktif**: Tampilan dan tombol dengan animasi yang menyenangkan.
- **Tombol "Menyerah" yang Menghindar**: Tombol ini bergerak menghindar saat kamu coba arahkan mouse ke atasnya.
- **Pesan Semangat**: Setelah memilih tombol "Siap!", kamu akan mendapat pesan semangat yang membakar semangat untuk terus berjuang.
- **Desain Futuristik**: Desain modern dengan latar belakang yang menawan dan elemen interaktif yang menambah energi.

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur dasar web.
- **CSS3 + SCSS**: Styling dan animasi untuk tampilan modern dan responsif.
- **JavaScript**: Interaksi dan animasi dinamis.

## 📦 Cara Menjalankan

1. **Clone repository ini ke dalam folder lokal**:
    ```bash
    git clone https://github.com/vorthrak/NATUS-VINCERE.git
    ```

2. **Buka file `index.html` di browser** untuk melihat hasilnya.

3. **(Opsional)** Untuk mengembangkan lebih lanjut, kamu bisa mengedit file SCSS dan HTML sesuai dengan kebutuhan.
